# Maison Fassi — site vitrine

Marque fictive (projet test). Next.js 16 (App Router) + TypeScript + Tailwind 4 + Framer Motion.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
npm run lint
```

- Contenus : `lib/content.ts`, `lib/catalog.ts` · configuration : `lib/site.ts`
